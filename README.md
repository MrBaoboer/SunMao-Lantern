# 榫卯灯笼 · 国风流光

**十三根木条，一颗钉子也不用。**

从十三根方料开始，一刀一刀开榫凿卯，<br />

## 这是什么

一节能动手的木工课，跑在网页里，给十岁往上的孩子和陪着他们的大人。

课本上的榫卯是一张剖面图，博物馆里的榫卯是一件不许摸的展品，都说不清**木头为什么能咬住木头**。
这里让你自己做一遍：四幕十八步，亲手拖、亲手锯，每一道槽都当场从毛坯上开出来。

| 幕 | 步 | 做什么 |
|---|---|---|
| **开场** | A1–A2 | 一盏灯，为一年收尾。不用钉子，它凭什么立得住 |
| **认识榫卯** | B1–B3 | 凸的叫榫，凹的叫卯。直榫穿过去，夹榫落下来 |
| **做骨架** | C1–C8 | 开槽、切榫、凿透眼、凿柱窝、削细颈，十三根木条合龙 |
| **装点年味** | D1–D5 | 选花纹、装格心、糊纸贴花，最后拆开看一遍 |

<div align="center">
<img src="docs/img/unlit.png" width="860" alt="还没点灯的成品：四面万字纹格心糊着绵纸，四角立柱与出头的榫" />
</div>

十八步走完就是它：四角出头的榫、四面镂空的棂条、糊在里面的绵纸。

做完之后还有四件事：**点灯**（按住不放，把灯点亮）、**猜灯谜**（答对一个，灯亮一分）、
**写心愿**（写一句话，存成一张海报）、**挂起来**（挂到夜色里，最多六盏）。

## 做起来是什么样

<div align="center">
<img src="docs/img/craft.png" width="420" alt="拖动凿子在顺枨顶面开出榫槽" />
<img src="docs/img/exploded.png" width="420" alt="三十六件构件的分层拆解" />
</div>

**加工是过程，不是动画。** 凿子压在哪条槽上，就只有那条槽在掉料；刀走到哪儿，料才少到哪儿。
手往回拖，木头不会长回去。

**拆开看，五层三十六件。** 底盘 5、上面的框 4、立柱 4、格心与纸 12、装饰与灯芯 11。
可以单看一层，也可以拉着滑块把整盏灯慢慢摊开。

**做不动也能往下走。** 需要动手的一步，按「下一步」会替你做一段：一条槽、一根柱子、一片格心。
旁边一直留着「帮我加工」「帮我装上」，想整步跳过就点顶上那一格。跳过的只是手感，该看到的一样不少。

**慢也没关系。** 旁白每秒三四个字，生僻字带注音；灯谜答错不扣分、不重来。

## 怎么操作

第一次进来会先讲一遍，右上角常留一个完整版。

| | |
|---|---|
| 两侧箭头 · `←` `→` | 上一步、下一步 |
| `空格` | 下一步 |
| 顶部小格 | 点一下跳到那一步 |
| 拖动 · 滚轮 | 转动、缩放，手机上双指开合。转到哪儿就停在哪儿 |
| `X` | 把灯笼拆开、调透明 |
| 右上角 `⋯` | 深色、声音、字幕，以及完整的操作说明 |
| `Esc` | 收起菜单与覆盖层 |

需要动手的步骤，构件直接拖。每一次装配只有一个合法方向，呼吸的小箭头会指出来；推歪了会轻轻弹回，并告诉你为什么。

手机上翻页在底部两角，屏幕两侧整片留给手指转动画面。
