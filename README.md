# 榫卯灯笼 · 国风流光

> 十三根木条，一颗钉子也不用。亲手做一盏能拆开的中式灯笼。

浏览器里的 3D 分步交互：从十三根方料开始，一刀一刀开榫凿卯，把一盏榫卯灯笼做出来，再点亮它。
主线 18 步，约 8 分钟；做完之后还有点灯、猜灯谜、写心愿、挂灯笼、放烟花五件事可做。

面向青少年，无需注册、无需下载，打开网页即可上手。

## 怎么操作

像翻书一样，翻页在两侧；顶上是四章，每一步一格，随便点哪一格都能跳过去。

| | |
|---|---|
| 两侧箭头 / `←` `→` / `空格` | 上一步 · 下一步。旁白没念完也能往前走 |
| 顶部小格 | 点一下跳到那一步 |
| 拖动 / 滚轮 | 旋转、缩放。每一步都有推荐机位，松手 3 秒自动缓回 |
| `X` | 拆开看看 —— 任意时刻剖切与拆解 |
| `Esc` | 关掉设置菜单或检视器 |
| 右上角 | 浅色／深色 · 声音 · 字幕 · 旁白朗读 · 拆开看看 · 尺寸对照 |

需要动手的步骤，底部中央会出现一个按钮；构件直接拖就行，每一次装配都只有一个合法方向。
不想动手时，每一步都有「帮我加工 / 帮我装上」，内容完整，只少一点手感。

界面默认浅色，可在右上角切到深色。傍晚与夜里的场景本来就该是暗的，那几步界面会自动跟着变暗，不影响你的选择。

## 几何是算出来的

这盏灯的木构件不是建模建出来的，而是按一套模数算出来的。

基本模数 a = 12 mm，所有尺寸都是 a 或 a/12 的整数倍，因此整套几何跑在整数毫米栅格上，没有浮点误差。
13 件木构件由「毛坯盒减去若干带工序标签的切除盒」生成，每一道工序 —— 铣槽、凿透眼、铣柱窝、切榫、开颈 —— 都是一次精确的布尔减法。

这样做换来三件事：

- **加工感不用画。** CSG 内核会标出哪些面是加工新露出的，着色器据此把新切面提亮一档。
- **穿模可以证伪。** 17 件构件两两求交，当前 136 组配对的重叠体积全部为 0。
- **面数很低。** 一根开满槽的顺枨 86 个三角形，17 件包络体合计 1152 个。

`src/core/verify.js` 里有 15 条断言，页面加载时自动跑一遍，结果输出到控制台；界面右上角的「尺寸对照」可以随时调阅。

## 音频

音效是实时模态合成的（`src/audio/sfx.js`），不是采样。因为它需要可参数化 ——「第二记音高高 2 个半音」「十三次落料随机 ±2 半音」「四根立柱到位音依次上行」—— 固定采样做不到。

声音只有三类来源：木头、纸、火。界面本身几乎不出声。

旁白与背景音乐留了挂载口，用什么工具录制或生成都行：

- 旁白 → `public/audio/vo/{编号}.mp3`，在同目录 `manifest.json` 里登记 `{ "ids": [...] }`
- 音乐 → `public/audio/bgm/{曲名}.mp3`，同理登记 `{ "files": [...] }`

全片旁白见 [旁白解说稿.md](旁白解说稿.md)，已分段断句、标好语速与停顿。
没有音频时，字幕按语速模型独立走完同一套内容，信息一句不少。

## 隐私

写心愿模块不采集任何个人信息：不要姓名手机号、不登录、不上传愿望内容。
海报在设备本地用 Canvas 合成，编号为本地生成的随机码，不含用户标识，也不可反查。

