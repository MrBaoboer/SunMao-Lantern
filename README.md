# 榫卯灯笼 · 国风流光

> 带你零距离感受惊艳千年的中式结构美学
> **13 根木条 · 0 颗钉子 · 0 滴胶水 · 可完整拆装**

浏览器端的 3D 分步交互：从十三根方料开始，一刀一刀开榫凿卯，把一盏榫卯灯笼亲手做出来，再点亮它。

## 跑起来

```bash
npm install
npm run dev
```

打开 <http://localhost:5173>。仅需 Chrome，无其他运行时依赖。

```bash
npm run build     # 静态产物 → dist/
npm run verify    # 几何闭合验算（Node，无需浏览器）
```

## 这是什么

一份 1487 行的《3D 交互脚本 V2.0》制作执行稿的**完整落地实现**：主线 24 步 + 五大互动模块（点灯 / 猜灯谜 / 许愿 / 挂灯笼 / 烟花）。

它有一点不太一样：**灯笼的几何不是建模建出来的，是按模数体系算出来的。**

原脚本 §3 规定基本模数 a = 12 mm，所有尺寸必须是 a 或 a/12 的整数倍。于是整套几何跑在**整数毫米栅格**上，零浮点误差；13 件木构件由「毛坯盒减去若干带工序标签的切除盒」参数化生成；每一道工序（铣槽、凿透眼、铣柱窝、切榫、开颈）都是精确的布尔减法。

由此得到三件白拿的东西：

- **加工感是算出来的** —— CSG 内核标记出「哪些面是加工新露出的」，着色器据此自动把新切面提亮一档
- **穿模是可以证伪的** —— 17 件构件两两求交，当前 136 组配对重叠体积全部为 0
- **面数极低** —— 一根开满槽的顺枨 86 个三角形（原预算 900）

原脚本 §13.1 那张给人对照勾选的「建模自检表」，在这里是 15 条**会自己报错的断言**，页面加载即跑。点界面右上角「校验」可以随时看报告。

## 操作

| | |
|---|---|
| 拖动 / 滚轮 | 旋转 · 缩放（每步有推荐机位，松手 3 秒自动缓回） |
| `←` `→` `空格` | 上一步 · 下一步 |
| `X` | 结构检视器 —— 任意时刻剖切与拆解 |
| 右上角 | 校验报告 · 检视器 · 声音 · 字幕 |

装配步骤直接拖动构件即可；每一次装配都是**单自由度约束**（原脚本 §6 的硬性要求），方向拖错会阻尼回弹并给出引导。不想动手的话，每步都有「自动装配 / 自动加工」的降级按钮，内容完整、只损失手感。

## 音频

音效是**实时模态合成**的（`src/audio/sfx.js`），不是采样。因为脚本本身要求音效可参数化——「第二记音高高 2 个半音」「十三次落料随机 ±2 半音」「四根立柱到位音依次上行」——固定采样做不到，实时合成天然做得到。

旁白与 BGM 由 MiniMax 生成，管线已就绪：

```bash
npm run gen:voice   # 36 条旁白
npm run gen:bgm     # 8 首 BGM
```

需要在 `.env.local` 里放 `MINIMAX_API_KEY`（该文件已在 `.gitignore` 中，不会入库）。
**未生成音频时字幕独立走完全同一套内容**，知识点零损失。
